# Taste Report Product Context

## 1. 제품 정의

Taste Report는 영화와 음악에 관한 짧은 질문을 통해 사용자의 실제 선택을 수집하고, 질문의 맥락과 콘텐츠 정보를 교차 분석해 취향을 하나의 재미있는 콘텐츠로 만들어 주는 서비스다.

핵심 경험:

```text
질문 → 콘텐츠 선택 → 의미 보존 → 공개 정보 조사 → AI 해석 → 캐릭터화 → 추천 → 공유
```

핵심 문장:

> 영화와 음악에 답하다 보면, AI가 내 취향을 알아보고 하나의 캐릭터로 만들어준다.

## 2. 사용자 가치

- 무엇을 좋아하는지 쉽게 떠올릴 수 있는 질문형 입력
- 선택한 작품과 답변을 알아봐 주는 구체적인 해석
- 공통점뿐 아니라 상황별 차이와 의외성의 발견
- 캐릭터·한줄평·성적표를 통한 재미있는 자기표현
- 취향과 연결되는 이유가 있는 새로운 콘텐츠 추천
- 친구나 SNS에 공유하기 쉬운 결과 이미지

주요 대상은 영화·음악 소비를 즐기고, 가벼운 테스트와 AI 해석 및 결과 공유에 관심이 있는 10~30대 사용자다.

## 3. MVP 범위

### 포함

- 영화 테마 우선 구현
- 테마별 질문지와 콘텐츠 검색·선택
- 질문 역할을 보존한 답변 확인
- 공개 정보 조사와 AI 분석
- 취향 캐릭터, 키워드, 한줄평, 성적표, 근거 있는 총평
- 추천 콘텐츠 3개
- 브라우저에서 생성하는 9:16 공유 이미지
- 영화 MVP 검증 후 음악 테마 추가

### 제외

- 회원가입과 계정
- 사용자 취향 이력 및 분석 결과의 영구 저장
- 저장된 결과를 다시 여는 고유 URL
- 자체 대규모 콘텐츠 데이터베이스
- 드라마·연예인 테마
- 영화와 음악을 합친 종합 취향 프로필
- 전문적인 심리 진단이나 능력 평가

## 4. 영화 질문의 역할

영화 질문은 단순 선호 목록이 아니라 작품과 맺는 관계, 취향의 경계, 추천 의도를 수집한다.

| 역할 | 수집 내용 | 해석 시 주의 |
|---|---|---|
| 선호 장르 | 장르 최대 3개 | 자기보고와 실제 선택의 차이도 관찰 |
| 인생 영화 | 가장 아끼는 영화 1편 | 선택 입력 설명을 최우선 근거로 사용 |
| 최근 만족작 | 최근 본 영화 중 만족한 작품 | 최근 개봉작일 필요 없음 |
| 장르 밖 의외작 | 평소 취향 밖인데 좋았던 작품 | 취향 확장의 근거 |
| 기대와 달랐던 작품 | 명작·추천작 중 맞지 않은 작품 | 입력하지 않은 불호 이유를 추정하지 않음 |
| 최애 캐릭터 | 영화와 캐릭터 | 해당 영화 전체를 좋아한다고 간주하지 않음 |
| 기억나는 대사 | 영화와 사용자의 기억 | 공식 인용으로 표시하지 않음 |
| 친구 추천작 | 힘든 친구에게 건넬 작품과 마음 | 개인 최애와 같은 의미로 처리하지 않음 |
| 추가 긍정 작품 | 아직 나오지 않은 선호작 최대 5편 | 긍정 선호 표본 보완 |

동일한 영화가 여러 질문에 등장할 수 있다. 분석에서는 작품 수를 중복 제거하지만 등장한 모든 역할을 보존한다.

## 5. 음악 질문의 역할

음악 질문은 깊은 개인사를 강요하지 않고 현재의 청취 습관과 상황별 선곡을 수집한다.

| 역할 | 수집 내용 | 해석 시 주의 |
|---|---|---|
| 선호 장르·가수 | 장르 최대 3개, 가수 최대 3팀 | 자기보고 단서 |
| 청취 상황·중요 요소 | 상황·요소 각각 최대 3개 | 사용자가 직접 밝힌 기준 |
| 최근 반복곡 | 요즘 많이 듣는 TOP 3 | 핵심 긍정 선호 |
| 마지막 청취곡 | 가장 마지막 곡 | 우연 가능성이 있어 낮은 가중치 |
| 차 안 첫 곡 | 함께 이동할 때의 선곡 | 사회적·활기 맥락 |
| 공부곡 | 집중 상황의 선곡 또는 해당 없음 | 음악을 듣지 않는 답도 유효 |
| 퇴근곡 | 하루를 끝내는 상황의 선곡 | 회복·전환 맥락 |
| 추가 추천곡 | 다른 사람에게 보여줄 곡 최대 5개 | 긍정 선호 보완 |

상황별 선곡을 개인 최애와 동일하게 취급하지 않는다. 음악 지식이나 수준을 평가하지 않는다.

## 6. 분석 원칙

1. 질문의 역할과 사용자 직접 입력을 콘텐츠 정보와 함께 전달한다.
2. 사용자 표현은 외부 작품 정보보다 우선한다.
3. 주요 해석은 어떤 답변에서 나온 것인지 설명할 수 있어야 한다.
4. 입력하지 않은 불호 이유, 성격, 개인적 동기를 단정하지 않는다.
5. 이번 답변 표본에서 나타난 경향임을 전제로 한다.
6. 근거가 부족한 지표는 축소하거나 생략한다.
7. 같은 콘텐츠의 반복 선택은 애착 단서로 사용할 수 있지만 서로 다른 여러 작품처럼 계산하지 않는다.
8. 추천 콘텐츠는 실재 여부와 관련성을 확인하고 이미 선택한 작품을 제외한다.
9. 취향 차이를 모순으로 몰지 않고 상황에 따른 변화로 설명할 수 있다.
10. 대중성·다양성·일관성 같은 점수는 고정 기준에 따른 재미용 AI 추정값임을 표시한다.

## 7. 결과 구조

공통 결과:

- 취향 캐릭터명과 보조 이미지
- AI 한줄평
- 핵심 키워드
- 취향 성적표
- 답변 근거가 연결된 총평
- 대표 콘텐츠와 의외의 선택
- 안전픽, 취향 확장, 도박픽 성격의 추천 3개
- 9:16 공유 카드

영화 리포트 관점:

- 네 취향의 본진
- 장르 밖에서 발견한 의외성
- 명작이어도 맞지 않았던 작품
- 최애 캐릭터와 기억에 남은 대사
- 친구에게 영화를 건네는 방식

음악 리포트 관점:

- 플레이리스트의 중심
- 말한 취향과 실제 선곡의 연결
- 혼자·함께·공부할 때의 선곡 차이
- 최근 반복곡과 오래 아껴온 곡의 관계
- 대표곡과 플레이리스트의 반전

## 8. 제품 언어와 안전선

- 친근한 반말을 기본 후보로 하되 전체 화면에서 일관되게 사용한다.
- 사용자의 선택을 조롱하거나 우열로 평가하지 않는다.
- ‘홍대병’, ‘음악력’ 같은 표현은 유머 장치일 뿐 객관적 수준을 뜻하지 않는다.
- 캐릭터는 실제 성격 유형이 아니라 이번 답변에서 드러난 취향을 표현한다.
- 정확한 진단보다 재미·구체성·공유 욕구를 우선하되 사실을 꾸며내지 않는다.

## 9. 성공 가설

- 질문형 입력이 자유 목록보다 완주하기 쉽다.
- 사용자는 자기 답변을 구체적으로 알아봐 주는 해석을 좋아한다.
- 캐릭터와 한줄평은 저장·공유 행동을 유도한다.
- 한 테마의 결과가 다른 테마 참여로 이어진다.
- 이유가 연결된 추천이 결과의 실용성을 높인다.
- 분석 1회 비용과 대기시간을 무료 경험 범위에서 관리할 수 있다.

## 확정된 결정

- 영화와 음악은 각각 독립된 질문 역할과 세션 초안을 유지한다.
- 초기에는 회원가입과 데이터베이스를 사용하지 않는다.
- 사용자 답변과 분석 결과는 영구 저장하지 않는다.
- 비밀키와 외부 공급자 호출은 백엔드에만 둔다.
- 결과 공유는 고유 URL이 아니라 9:16 이미지 저장·공유를 우선한다.
- AI 분석은 질문별 의미를 보존한 구조화 입력과 구조화 출력을 사용한다.
- 제품 해석 규칙은 `.ai/PRODUCT.md`를 기준으로 한다.

## 블로커와 사용자 결정 필요 사항

- 영화 검색은 키와 이용료가 없는 Wikidata(CC0)와 Wikimedia Commons 이미지를 사용한다. Commons 이미지는 파일마다 라이선스가 달라 현재 UI가 개별 크레딧을 표시하며, 모든 작품의 공식 포스터를 보장하지는 않는다.
- 공개 배포 전 Wikimedia 접근 정책에 맞게 `WIKIMEDIA_USER_AGENT`에 실제 서비스 URL 또는 연락처를 설정해야 한다.
- 음악 검색은 인증키가 필요 없는 Apple iTunes Search API의 US 스토어를 사용한다. 한국어 가수·곡 실제 검색을 확인했다.
- AI 모델 및 분석 예산 미정
- 배포 플랫폼 미정

이 항목들은 현재 영화·음악 질문지의 정적 화면·상태 구현을 막지 않는다.

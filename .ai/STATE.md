## 다음 마일스톤: 실제 영화 검색

완료 조건:

- FastAPI에 TMDB 어댑터와 영화 검색 라우트가 구현된다.
- 공급자 비밀키가 프론트 번들에 포함되지 않는다.
- 검색 결과가 공통 `CatalogItem` 계약으로 변환된다.
- 입력 디바운스, 취소, 로딩, 빈 결과, 오류와 재시도가 구현된다.
- TMDB 출처 표기와 포스터 사용 조건을 화면에 반영한다.
- 백엔드 pytest·Ruff, 프론트 타입 검사·빌드와 `/api` 프록시를 검증한다.

구현 방향:

- React/Vite는 정적 브라우저 앱이므로 TMDB 키를 `VITE_` 변수에 넣지 않는다.
- FastAPI에는 Claude 분석 로직과 분리된 얇은 TMDB 공급자 어댑터와 검색 프록시만 추가한다.
- 프론트엔드는 현재 `CatalogItem` 타입을 유지하고 로컬 샘플 검색 함수만 API 호출로 교체한다.
- 음악 질문지 구현 시에는 키가 필요 없는 Apple iTunes Search API의 브라우저 직접 호출을 우선 검증한다.
- Spotify는 2026년 Development Mode 제약 때문에 MVP 기본 공급자로 사용하지 않는다.
